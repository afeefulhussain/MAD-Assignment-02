⚡ 2. Task 1: CRUD & Array Methods Breakdown

The application implements an array of objects to manage records locally with full CRUD operations:

➕ Create Record

Form modal with validation (Roll No, Name, Department, Email, Phone, Status). Enforces unique roll number via records.some().

📋 Read Record

Dynamically renders all records via FlatList with custom elevated cards, contact icons, and status chips.

✏️ Update Record

Edit modal retrieves specific record using Array.find(), allows modification, and commits changes immutably with Array.map().

🗑️ Delete Record

Prompts confirmation dialog and removes the target student from device state and AsyncStorage using Array.filter().

🌐 3. Task 2: Free Public API Integration (Axios)

Integrated free public REST API: https://jsonplaceholder.typicode.com/users
Fetches live JSON data on component mount via axios.get(). 

import axios from 'axios';

const fetchApiData = async () => {
  setLoading(true);
  setError(null);
  try {
    const response = await axios.get('https://jsonplaceholder.typicode.com/users', {
      timeout: 6000,
      headers: { Accept: 'application/json' },
    });
    setData(response.data);
  } catch (err) {
    setError(err.message || 'Failed to fetch public API data.');
  } finally {
    setLoading(false);
  }
};
⏳ Loading State

Shows an animated ActivityIndicator while network request is in-flight.

⚠️ Error Handling

Displays user-friendly error banner with an interactive Retry button if connection drops.

🔄 Pull-to-Refresh

Supports native pull-down swipe to reload fresh JSON records directly from the server.
